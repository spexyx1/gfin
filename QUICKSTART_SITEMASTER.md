## Common Tasks

### Suspend a User
1. Go to **Users** tab
2. Search for user
3. Click **Ban icon** (🚫)
4. Enter reason & duration
5. Confirm

### Disable a Feature
1. Go to **Features** tab
2. Find feature
3. Click **toggle button**
4. Done

### Adjust a Rate
1. Go to **Rates** tab
2. Find rate
3. Enter new value
4. Click **Update**

### Force Release Escrow
1. Go to **Escrow** tab
2. Find order
3. Click **green checkmark** (✓)
4. Enter reason
5. Confirm

### Flag a User
1. Go to **Users** tab
2. Search for user
3. Click **Flag icon** (⚠️)
4. Enter type & reason
5. Submit

### Message a User
1. Go to **Users** tab
2. Search for user
3. Click **Message icon** (💬)
4. Write message
5. Send
